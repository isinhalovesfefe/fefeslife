# fefe's life

jogo feito com carinho pra fefe.

## como rodar

abra o `index.html` num servidor (ex: github pages ou netlify).

## pastas

- `index.html`: a página do jogo
- `css/`: estilos
- `js/funcoes/`: as funções de cada parte do jogo
- `js/`: os dados e o que roda quando o jogo abre (carregados na ordem do `index.html`)
- `sons/`: miados, ronrom e buzinas
- `musica/`: músicas do jogo
